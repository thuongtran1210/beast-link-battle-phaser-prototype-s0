# STYLE_BIBLE.md — Cute Tactical Chibi

Status: **Current Art Source of Truth**

## 1. Style identity

Name:

**Cute Tactical Chibi**

Visual target:
- Gen Z-friendly
- cute but not childish
- tactical
- readable at gameplay scale
- polished but restrained
- graphic rather than painterly
- intentionally designed rather than ornament-heavy

## 2. Proportion

Default semi-chibi proportion:

- head: approximately 35–40% of total height
- body: approximately 60–65%

Avoid:
- baby proportions
- giant heads above the target range
- oversized glossy anime eyes
- tiny limbs that make combat pose unreadable

## 3. Rendering

Use:
- 2D illustrated game asset
- colored medium-weight outline
- slightly stronger outer contour
- simpler internal linework
- flat/clean base colors
- 1–2 cel-shading steps
- minimal controlled highlights
- subtle texture only
- low-to-medium detail density

Avoid:
- photorealism
- painterly splash art
- pseudo-3D render
- plastic surfaces
- excessive material rendering
- hyper-detailed fur
- cinematic lighting inconsistent across assets

## 4. Silhouette rule

Silhouette is more important than decorative detail.

At small scale, the player should be able to identify:
- player vs enemy
- Role/archetype
- broad action direction

before reading text.

## 5. Motif budget

Each character should have:
- 1 primary silhouette concept
- 2–3 primary identity motifs
- 1 controlled accent

Do not add decorative detail merely to fill space.

## 6. Palette family

Base:
- cream / off-white
- lavender
- sky blue
- mint
- peach
- butter yellow
- soft coral

Accents:
- electric cyan
- violet
- restrained hot pink
- soft gold
- light lime

Neutrals:
- desaturated navy
- soft charcoal
- warm gray

Guidelines:
- about 4–5 main colors per unit
- one dominant accent
- player Beasts may be more saturated than enemies
- enemy palette should support archetype readability

Exact production color values remain open until the first Master Reference is approved.

## 7. Camera / pose family

Default:
- full body
- 3/4 front view
- neutral combat-ready pose
- consistent contact/ground logic
- no extreme lens perspective
- no cinematic low-angle
- production character assets use transparent background

When a set shares a battle-facing direction, keep the direction consistent across the set.

## 8. Face language

Use:
- simple readable eyes
- small mouth
- clear brows/eye angle
- role-specific expression

Avoid:
- same face on every Beast
- giant sparkling baby eyes
- human-anime face pasted onto an animal body

Role mood:
- Tanker: calm, sturdy, determined
- Assassin: sharp, mischievous, alert
- Ranger: focused, agile
- Mage: curious, composed, slightly mystical

## 9. Material simplification

Prefer a few readable material families:
- soft creature/fur mass
- cloth
- simple armor
- crystal/energy accent

Materials should be stylized consistently.

Do not make one Beast physically rendered while another is flat-cartoon.

## 10. FX

FX are gameplay communication.

Use:
- graphic shapes
- clear timing
- limited particle count
- controlled glow
- strong impact silhouette

Avoid:
- noisy particles
- full-screen bloom
- visual effects that hide positioning

## 11. UI relationship

UI should support the same direction:
- rounded but structured
- friendly
- clean spacing
- pastel base with controlled accents
- readable typography
- not over-glassmorphed
- not ornate fantasy UI

## 12. Master Reference rule

This Style Bible is text-level law.

Once Snowguard is STYLE APPROVED, the approved visual becomes the image-level law.

Text and reference should then be used together.
