# ASSET_QA_CHECKLIST.md

Use this before promoting an asset status.

## Critical style checks

- [ ] Semi-chibi head/body ratio matches the target family.
- [ ] Full-body silhouette is readable at small scale.
- [ ] Role/archetype is readable without text.
- [ ] Outline weight matches the Style Bible / Master Reference.
- [ ] Shading depth is limited to the approved cel-shading approach.
- [ ] Camera/perspective matches the approved family.
- [ ] Detail density is low-to-medium and intentional.
- [ ] Palette stays inside the approved family/subset.
- [ ] Only 2–3 primary motifs are competing for attention.
- [ ] Asset feels consistent with the Master Reference, if one exists.

## Anti-AI checks

- [ ] No random jewelry.
- [ ] No unexplained crystals.
- [ ] No decorative gold filigree spam.
- [ ] No hyper-detailed fur.
- [ ] No glossy 3D/plastic treatment.
- [ ] No rainbow rim lighting.
- [ ] No excessive bloom.
- [ ] No unnecessary background.
- [ ] No malformed/duplicated anatomy or accessory artifacts.
- [ ] No meaningless symbols/text.

## Gameplay-readability checks

- [ ] Role/archetype remains readable at intended gameplay size.
- [ ] Attack/facing direction is understandable.
- [ ] FX do not erase the silhouette.
- [ ] STAR overlays, if any, preserve the base identity.
- [ ] Signature motif supports the actual gameplay identity rather than inventing a new mechanic.

## Status rule

### DRAFT
Early candidate. QA may fail.

### REVIEW
All critical style checks pass. Candidate is ready for owner review.

### STYLE APPROVED
Owner explicitly approves it as part of the visual source of truth.

### GAME READY
Approved asset has correct production format, scale, transparency/crop and integration requirements.

If 2 or more critical style checks fail, do not promote to REVIEW.
