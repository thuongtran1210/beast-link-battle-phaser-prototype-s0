# P1-V13A — Beast Signature Identity

Status: Experimental / not adopted.

This slice gives beast-a through beast-d deterministic, automatic signatures defined by beast identity: Guardian Brace, Ambush Strike, Focus Shot, and Arcane Bloom. Values are isolated in `P1V13A_SIGNATURE_FIXTURE`; canonical gameplay values are unchanged.

Arcane Bloom evaluates its cluster at normal cast resolution. The layer uses the existing fixed-step timeline, engagement system, and damage path; it adds no mana, player buttons, or generic ability framework.
