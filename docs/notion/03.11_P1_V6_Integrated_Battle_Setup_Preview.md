# 03.11 — Experimental Variant P1-V6 — Integrated Battle Setup Preview

> **Status:** Experimental · implemented · orientation hotfix applied after live verification feedback · re-verification pending. Not adopted into Current Gameplay Spec.
## Goal
Keep the logical BattleSetup phase and gating, but present it on the same mirrored battlefield layout used by Battle.
## Presentation Rules
- Player formation grid remains on the left side.
- P1-V5 enemy squad preview remains visible on the opposing right side.
- Player can place/reposition units directly on the player side while seeing enemy positions.
- Stored Energy, Unplaced Units, and Start Battle remain available in the setup panel.
- Start Battle remains disabled until all converted units are placed.
- Pressing Start Battle transitions to Battle using the same battlefield slot geometry.
## Non-Goals
- No change to state graph.
- No change to formation rules.
- No change to enemy targeting/combat math.
- No enemy rearrangement by the player.
- No final art / hex-grid production implementation.
- No Current Gameplay Spec adoption.
## Implementation Update — 2026-10-02
- Added shared `BattleFieldLayout.ts` for player/enemy slot geometry.
- `BattleActionView` now uses the shared battlefield layout.
- `BattleSetupView` now renders the same mirrored battlefield as a setup preview.
- P1-V5 enemy fixtures are injected into Battle Setup preview.
- ValidationScene labels the build as P1-V6 Experimental.
## Live Verification Finding — 2026-10-02
- Initial P1-V6 verification exposed incorrect battlefield orientation: both sides rendered Front / Mid / Back in the same direction instead of facing each other.
- Shared battlefield geometry has been corrected so Player Front is nearest the center from the left, Enemy Front is nearest the center from the right, and Mid / Back retreat outward on each side.
- Formation columns 1–6 now map to vertical lanes shared by both sides.
- Hotfix commits: `6cc99d53...`, `8ae280fa...`, `8a57155e...`.
