```plain text
Tiếp tục dự án Beast Link Battle.

2. 00 — Beast Link Battle — Current Gameplay Spec v2

6. 02.4 — P1 Technical Scaffold — Dual Queue + Tactical Battle

Sau khi đọc, chỉ báo:
- current milestone,
- latest verified state,
- current blocker,
- next action duy nhất.

Không suy diễn rule còn thiếu.
Không dùng Unity implementation làm Design Source of Truth.
Không mở rộng scope trước khi blocker hiện tại được xử lý.
```

## Sync rule
- Trang handoff là nơi cập nhật milestone/blocker/next action.
- Trang này giữ prompt resume độc lập để tránh thất lạc khi handoff được chỉnh sửa.
- Khi prompt thay đổi có chủ đích, đồng bộ cùng file Git `docs/NEW_CHAT_RESUME_PROMPT.md`.
