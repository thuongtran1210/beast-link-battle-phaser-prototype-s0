# Camp & Dorm — first playable prototype

Owner-authorized persistent camp presentation outside the Run. Menu has Camp & Dorm; choosing it does not start or alter a Run.

- Local device save `beast-link-camp-v1`, sanitized on load; first visit grants 25 wood.
- Actual Beast recruitment at Setup preparation discovers residents, independent of later KO or Run defeat. All ten current player types are supported. Harness recruitment does not write camp state.
- A full player Run victory grants 15 wood, guarded against repeated Result entry for that Run. Restart resets the reward guard. Partial Wave victories and defeats grant no wood.
- Three decoration positions; tub (10), giant carrot (15), toy forge (20). Crafting spends once; moving an owned item and clearing a position are free, with no duplicate placement of the same item.
- Resident cutouts wander/bob. Tap to interact; Snowguard uses placed tub, Windstrider uses carrot, Ironclad uses forge. Lightweight soaking/nibbling/hammer animation and contextual dialogue; these are transform interactions on existing cutouts, not newly authored animation sheets or autonomous AI routines.
- Diary records arrivals and the first favorite-item dialogue; last 12 entries displayed, capped at 30 saved entries. All narrative content rendered as text.
- Mobile landscape and portrait layout, reduced-motion support. No crystal currency, expansion purchase, polaroid export or Run buff in this slice. These are deferred systems, not present controls.

Deterministic tests cover initial state, crafting cost, owned-item movement, insufficient funds, invalid slots, malformed saves and serialization. Check/build evidence is separate from a live phone review; no device visual pass is claimed.
